Klirr licenses
==============

Klirr is free and open-source software. Its source code is licensed under the MIT License
(Klirr-MIT.txt).

The Windows installer contains two builds of Klirr and installs one of them:

- Without ASIO support, the installed program (klirr.exe) is licensed under the MIT License.

- With ASIO support, klirr.exe also contains the Steinberg ASIO SDK, which Klirr uses under
  the GNU General Public License, version 3. The program as a whole is then licensed under
  the GPLv3 (GPL-3.0.txt). Klirr's own source code stays available under the MIT License.

Klirr's Help > About shows which of the two is installed.

Both builds also contain third-party open-source software, each part under its own license:
THIRD-PARTY-NOTICES.txt lists it, with the license texts and copyright notices.
